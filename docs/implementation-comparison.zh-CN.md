# 本项目实现对照与相对朝向消融

2026-10-27（America/Los_Angeles）。对照版本、逐项源码及外部成绩见 [社区代码审查](community-code-audit.zh-CN.md)。本文记录本项目实际实现，不把社区成绩当成本项目结果。

| 项目 | 本项目基线 | 社区实现差异 | 本轮处理 |
|---|---|---|---|
| 本体观测 | 93×10，term-major历史 | vibed为99×10；Go-Youngster/LaoYang可保持93×10 | 保持930维不变 |
| 参考目标 | 10×68，不含相对位姿 | YanYuan支持当前6D相对朝向；LaoYang/Go-Youngster含每未来帧相对朝向；dhmbb2含相对位置 | 新增当前躯干朝向6D，总686；不同时更改未来参考表示 |
| 仿真/想象目标 | 已有9D相对位姿可选项 | 目标依赖当前或预测的机器人姿态 | 6D路径从真实/预测FK躯干姿态重算，保留BPTT梯度；噪声均为U±0.05 |
| 计分 | 完整N−1参考区间分母，失败后缀为0 | Cuboi旧代码为执行步分母；多家已改完整分母 | 保持full-reference-v1；补记录评估checkpoint更新数 |

| 世界模型/critic | 71维状态、学习终止头；完整状态critic；TF32 | 社区也有解析软终止、额外FK特征、运行归一化、bf16、值裁剪 | 不同时增加这些改动 |

6D表示为 `R_robot_torso^T R_reference_torso` 的前两列，按行展平。它通过当前机器人躯干姿态反馈参考朝向；不读取机器人位置。不是每未来帧的相对朝向序列，也不是9D相对位姿。参考航向的初始对齐和IMU漂移仍是部署假设。论文未列全g_t，不能认定其中任何一个编码就是原作者实现。

本轮新增的关键验证：已知旋转的数值和导数；686/689互斥及仅改变目标的配置检查；仿真目标与独立mjlab朝向函数对拍；想象每一步与预测FK旋转矩阵乘积对拍、梯度有限且保留姿态敏感性/水平平移不敏感；包含新输入的训练、保存及恢复。GPU验证结果和正式训练状态随后记录在 [实验日志](experiments.md)。

实验计划：新建 `lafan1-ori6-current-full-state-seed0`，随机初始化，seed0，4096环境、k8、H32、与基线相同三小时预算、完整40动作评估。基线最佳32000采集步/12784更新/return0.569920；只在相同评估口径下比较，并同时观察未对齐的全局根轨迹和失败动作。单种子对照只能提供线索，不能建立统计稳健性。

运行环境按当前共享服务器存储规则调整：环境/编译缓存迁至NVMe，输入进入每个Slurm作业的RAM临时目录，最终日志/权重仍写持久盘。这是执行位置变化，包版本、数据哈希、物理设置和学习超参数保持不变；编译/启动耗时仍计入预算。

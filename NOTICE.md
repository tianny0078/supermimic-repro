# Provenance

This project is an unofficial reproduction of *SuperMimic: Scaling Humanoid Whole-Body Control with One Differentiable World Model*, Liao et al., arXiv:2610.28480. It is not affiliated with the paper authors.

The initial Python implementation, tests, data conversion scripts and dependency lock were adapted from CuboiLeo/SuperMimic-Reproduced, commit d9be385b3eeb (full revision recorded in `docs/upstream-revisions.json`), Copyright (c) 2026 Yuxi Liu, under the MIT license reproduced in `LICENSE`. Changes in this repository are documented in Git and `docs/paper-contract.md`. We do not claim the upstream code was authored here or that upstream experimental results were obtained here.

Other implementations were read for comparison. Their results are third-party reports, not validation of this code. MuJoCo, MuJoCo Warp, mjlab, Unitree assets and motion datasets retain their own licenses. No motion dataset or trained checkpoint is redistributed by this repository.

LAFAN1 source motions are licensed CC BY-NC-ND 4.0; the retargeted dataset declares separate terms for the Unitree robot assets. Use is subject to those source terms.
